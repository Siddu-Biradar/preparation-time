⚡ Async Patterns

Retry, Queue, Concurrency Limiter, Sequential Execution

1. Retry with Exponential Backoff

Simulates flaky API that fails 70% of the time. Retries up to 4 times with increasing delays.

2. Promise Pool — Concurrency Limiter (limit=3)

8 tasks but only 3 run at a time. Watch how new tasks start as old ones finish.

3. Sequential Async Execution (waterfall)

Tasks run ONE at a time, each waits for the previous to finish.

4. Async Task Queue (FIFO with concurrency)

Enqueue tasks dynamically — they execute in order respecting concurrency limit.

5. Cancellable Fetch with AbortController

Start a slow request, then cancel it before it finishes.
