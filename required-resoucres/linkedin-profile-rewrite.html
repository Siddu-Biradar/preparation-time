Our frontend bundle was 43MB.

Yes, forty-three megabytes. For a web app.

Users waited 12+ seconds for first load. The app felt broken.

Here's how I cut it to 1.8MB (95% reduction):

1. 🔍 Audited with Webpack Bundle Analyzer — found 3 libraries we imported but never used
2. 🌳 Enabled tree-shaking properly — Angular's default config wasn't enough
3. ✂️ Code-split every route — went from 1 monolithic bundle to 12 lazy-loaded chunks
4. 📦 Replaced moment.js (300KB) with date-fns (30KB)
5. 🗜️ Added Brotli compression — 40% smaller than gzip
6. ⚡ Implemented performance budgets in CI — any PR that adds >50KB gets flagged

Result:
→ Load time dropped from 12s to 2.1s
→ Core Web Vitals went from "Poor" to "Good"
→ Zero user complaints about speed since then

The lesson? Performance isn't a feature. It's the product.
