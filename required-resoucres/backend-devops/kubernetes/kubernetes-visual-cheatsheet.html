🏗️ Cluster Architecture — Control Plane vs Worker Node

Your Pods (Containers) what you actually deploy
kubelet + kube-proxy + container runtime runs on every Worker Node
Worker Node OS / Kernel
Control Plane API Server, Scheduler, Controller Mgr, etcd
Physical / Cloud Infrastructure
Nodes: many machines Pods: many per node Self-healing: automatic

📐 Resource Ownership Hierarchy

Deployment declares replica count + rollout strategy
ReplicaSet auto-created; keeps N Pods alive
Pod(s) 1+ containers, shared network/IP
Container(s) your actual running app process
Update via: rollout Rollback: 1 command Self-heals: ReplicaSet
🧭 Cluster & Context
kubectl cluster-info / get nodes -o wide
kubectl config get-contexts
kubectl config use-context my-dev-cluster
kubectl config set-context --current --namespace=dash
kubectl api-resources / explain deploy.spec
📦 Pods
kubectl get pods -o wide
kubectl describe pod app-abc123
kubectl logs -f app-abc123 --previous
kubectl exec -it app-abc123 -- sh
kubectl delete pod app-abc123
kubectl top pod app-abc123
🚀 Deployments & Rollouts
kubectl get / describe deployment app
kubectl scale deployment app --replicas=5
kubectl set image deploy/app app=img:tag
kubectl rollout status deployment/app
kubectl rollout undo deployment/app
kubectl rollout restart deployment/app
🌐 Services & Ingress
kubectl get svc / describe svc app-svc
kubectl get endpoints app-svc
kubectl port-forward svc/app-svc 8080:80
kubectl expose deployment app --port=80
kubectl get / describe ingress app-ing
🔧 ConfigMaps & Secrets
kubectl create configmap app-cfg \
  --from-literal=LOG_LEVEL=debug
kubectl create secret generic app-secret \
  --from-literal=DB_PASS=xxxx
kubectl get configmap app-cfg -o yaml
kubectl get secret app-secret -o jsonpath='{.data.DB_PASS}' | base64 -d
🏷️ Namespaces & Labels
kubectl get namespaces
kubectl get pods -n dash / -A
kubectl label pod app debug=true
kubectl get pods -l app=di-jfrog
kubectl annotate pod app owner=squad-di
🔍 Debugging
kubectl describe pod app-abc123 #1 debugging command
kubectl get events --sort-by='.lastTimestamp'
kubectl debug -it app-abc123 \
  --image=busybox --target=app
kubectl get pod app-abc123 -o yaml
kubectl get pod app-abc123 -o jsonpath='{.status.conditions}'
⛵ Helm
helm upgrade --install app ./chart \
  -f values.yaml
helm get values app
helm template ./chart -f values.yaml
helm list / helm history app
helm rollback app 3
helm lint ./chart
